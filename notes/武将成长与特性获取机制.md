# 中华三国志：武将成长、称号/技能/特技获取机制详解

> 版本：中华三国志 1.23.1-1.24.1（Release，.NET Framework 4.8）
> 代码依据：`D:\re\zhongsan\ilspy\`（ILSpy 反编译）
> 数据依据：`Release\Content\Data\Common\CommonData.json`、`Release\Content\Data\Scenario\*.json`、`Release\Content\Data\GameParameters.xml`、`Content\Data\GlobalVariables.xml`
> 说明：本文只讲“游戏内怎么长出来”，不涉及改档工具本身。所有行号指反编译源码。

## 0. 一句话结论

- **五维 = 基础值（数据文件里写死） + 经验换算值 + 称号/技能/宝物加成**，最后乘疲劳、年龄、关系、怀孕、受伤系数，单条属性封顶 400。
- **经验**主要来自：城池内政工作（每项工作加不同的五维）、征兵/训练、战斗、抢粮、断路、城内训练设施。
- **称号**只有 5 条来源：数据预置、每日自动学习、君主授勋、花钱派城学习（90 天）、子女继承。其中 1302 个称号里有 **668 个标了“无法习得”**，只能靠剧本数据预置——**超模女性武将的超模称号全部属于这一类**。
- **技能**来源：数据预置、每日自动学习（10%/项）、派城学习 30 天（一次结算学会所有满足条件的）。
- **特技**来源：数据预置、每日自动学习（10%/项）、派城学习 60 天（一次只学一个）。
- 一句话：**游戏里能长出来的属性是有天花板的；“456 五维 + 妖后降临 Lv12 + 33 技能”这种是作者直接写进剧本的，不是练出来的。**

## 1. 五维与经验

### 1.1 数据结构

每个人物在 JSON 里有两套数值：

| 字段 | 含义 |
|---|---|
| `BaseCommand / BaseStrength / BaseIntelligence / BasePolitics / BaseGlamour` | 基础五维（统率/武勇/智谋/政治/魅力），数据文件里写死 |
| `CommandExperience / StrengthExperience / IntelligenceExperience / PoliticsExperience / GlamourExperience` | 五项经验，游戏内成长，随存档保存 |
| `InternalExperience` | **内政经验**，独立数值，不算五维（见第 5 节） |
| `IncrementOf… / RateIncrementOf…`（运行时） | 称号、技能、特技、宝物带来的加值与倍率，不落盘，读档时由 `ApplyInfluence` 重新施加 |

### 1.2 经验 → 属性

`GameObjects/Person.cs:1923`：

```csharp
public int CommandFromExperience => (int)Math.Pow(CommandExperience / 1000, 0.9);
```

- 经验 1000 → +1，经验 1 万 → +7，10 万 → +63，30 万（上限）→ +170。
- 经验上限 `maxExperience = 300000`（`Content\Data\GlobalVariables.xml`）。

### 1.3 显示值公式

`GameObjects/Person.cs:2598`（其余四项同构）：

```csharp
NormalCommand = (int)(
    Math.Min((CommandIncludingExperience + InfluenceIncrementOfCommand) * InfluenceRateOfCommand,
             GlobalVariables.MaxAbility)          // 单条属性硬上限 400
    * TirednessFactor * AbilityAgeFactor * RelationAbilityFactor
    * huaiyunAbilityFactor * InjureRate);
```

- `MaxAbility = 400`（GlobalVariables.xml）。
- `TirednessFactor = max(0.2, min(1, (210 − 疲劳) / 180))`（Person.cs:1040）。
- `AbilityAgeFactor`：未成年按 `AGE_FACTORS` 递减，60 岁后 `max(0.2, −0.016×年龄+1.96)`；`EnableAgeAbilityFactor=false` 时恒为 1。
- `RelationAbilityFactor`：与君主关系（亲近/厌恶）影响，`CloseAbilityRate/VeryCloseAbilityRate=1.1`。
- `huaiyunAbilityFactor`：怀孕/产后恢复期折扣（魅力、武勇另有单独系数）。
- `InjureRate`：受伤折扣。

> 注意：上限 400 是**单条属性**，不是五维总和。所以“五维 456”是完全可能的：作者把基础值写超了。

### 1.4 每次加经验的乘数

`Person.AddCommandExperience` 等（Person.cs:4378 起）：

```
最终增量 = 基础增量 × AbilityExperienceRate(1)
         × (1 + 人物 ExperienceRate) × (1 + 所在城池 ExperienceRate) × (1 + 所在部队 ExperienceRate)
         × (玩家 ? 1 : AIOfficerExperienceRate(1))
```

## 2. 哪些工作加哪些属性（核心表）

城池里每种内政工作对上场的武将结算一次，随机值 ≈ `工作能力 / (500 + 150 × (辖区数 − 1))`（`StaticMethods.GetRandomValue`，`GameGlobal/StaticMethods.cs:211`），然后按固定比例分给各项经验。每天结算（`Architecture.DevelopDay`）。

| 工作 | 代码 | 加的经验（倍数） | 工作能力公式（决定效率） |
|---|---|---|---|
| 农业 | `Architecture.cs:7809` | 内政×2、**政治×2、魅力×2** | 2×(政治+魅力) |
| 商业 | `Architecture.cs:7854` | 内政×2、**智谋×1、政治×2、魅力×1** | 智谋+2×政治+魅力 |
| 统治 | `Architecture.cs:7929` | 内政×2、**武勇×2、统率×1、魅力×1** | 2×武勇+统率+魅力 |
| 耐久 | `Architecture.cs:7969` | 内政×2、**武勇×1、统率×1、智谋×1、政治×1** | 武勇+统率+智谋+政治 |
| 民心 | `Architecture.cs:8051` | 内政×2、**统率×1、政治×1、魅力×2** | 统率+政治+2×魅力 |
| 技术 | `Architecture.cs:8115` | 内政×2、**智谋×2、政治×2** | 2×(智谋+政治) |

要点：

- **想练哪条属性，就派他去做对应工作**：政治→农业/商业/技术，魅力→农业/民心，武勇→统治/耐久，智谋→商业/耐久/技术，统率→民心/耐久。
- 每项工作都额外给“内政经验×2”（见第 5 节）。
- 工作还会涨名声（`Reputation`）、功绩（`OfficerMerit`）、势力名声/技巧点。
- 只有**被放进该工作槽**的人才会涨；`InternalNoFundNeeded`（不耗资金）的人跳过扣钱判定。
- 若势力资金不足付 `InternalFundCost`（每回合 5），该次工作不结算、不涨经验。

## 3. 军事与战斗经验

| 行为 | 代码 | 加的经验 |
|---|---|---|
| 征兵 | `Architecture.cs:12646` | 征兵经验、**统率 +value/2、魅力 +value/2** |
| 训练（士气） | `Architecture.cs:13643` | **统率 +value×2** |
| 训练（战意） | `Architecture.cs:13678` | **武勇 +value** |
| 战斗攻击 | `Troop.cs:10500` 附近 | **武勇**（主将 ×2，其余 ×1） |
| 战斗受击/防御 | 同上 | **统率**（主将 ×2，其余 ×1） |
| 破坏道路 | `Troop.cs:6449` 附近 | **武勇/统率/智谋 各 +value×5** |
| 随军抢粮（LevyFood） | `Troop.cs:11037` 附近 | **统率、魅力**（按粮量/10000） |
| 单挑/挑战 | `Person.ChallengeStrength` | 只影响单挑判定，不额外加经验 |

另有城池设施“训练”类建筑（练兵所、演武场等）：

`Architecture.FacilityTrainCommand/Strength/Intelligence/Politics/Glamour`（`Architecture.cs:14249` 起）：

```
每次：扣 200 金（TrainAbilityCost），疲劳 +25（TrainAbilityTiredness=5，5×5），
     对应经验 += 50 × 该设施等级倍率（TrainAbilityAmount=50）
```

对应设施率：`CommandTrainingFacilityRate / StrengthTrainingFacilityRate / IntelligenceTrainingFacilityRate / PoliticsTrainingFacilityRate / GlamourTrainingFacilityRate`（另有枪/骑/弩/水/器械训练设施给兵种经验）。

> 所以“训练设施”是**唯一能直接用钱换五维经验**的途径，但每次只 +50、还要加 25 疲劳，性价比低。

## 4. 关系、宝物、官爵的加成

- 称号/技能/特技/宝物在获得时通过 `Influences.ApplyInfluence(person, applier, id, excludePersonal)` 一次性把 `IncrementOf…`（固定加值）和 `RateIncrementOf…`（百分比）写到人物身上；失去时 `PurifyInfluence` 扣回。
- 因此**删掉一个称号，等于同时删掉它附带的所有加值与战斗特效**（这也是清理超模称号最有效的原因）。
- `PersonalTitleString`（个人称号，默认全 0 = 超世之杰）在正常载入路径下**不生效**：`Person.LoadTitleFromString`（Person.cs:4323）只在 `RealTitlesString` 解析抛异常时才回退使用它。
- 称号同类只能有一个：`LearnTitle`/`AwardTitle` 会先移除同 `Kind` 的低级/旧称号（Person.cs:6994 起）。

## 5. 内政经验（InternalExperience）

- 独立数值，上限同样 300000，**不换算成五维**。
- 来源：所有城池内政工作都会给“内政经验×2”（农业/商业/统治/耐久/民心/技术），是量最大的一种经验。
- 用途：
  - 作为称号/技能的**学习条件**（条件表里大量“内政经验值达到 1000/2000/…”）；
  - 条件表 `ConditionKinds` 里出现频率最高的就是这一类；
  - “操劳过度”死亡判定会累计各项经验（Person.cs:4883）。
- 显示名在游戏里就是“内政”，所以一个从不带兵、只做内政的文官，内政经验会很高而五维涨得慢。

## 6. 称号（Title）获取机制

### 6.1 五条来源

| # | 来源 | 代码 | 说明 |
|---|---|---|---|
| 1 | **数据预置** | `RealTitlesString`（读：`Person.LoadTitleFromString` Person.cs:4323；存：`GameScenario.cs:4571`） | 剧本/存档里直接写称号 ID，一读档就生效。**超模称号全部走这条** |
| 2 | **每日自动学习** | `GameScenario.cs:1380 titleDayEvent()`（在 `DayPassedEvent` 内） | 每天遍历所有 `AutoLearn > 0` 的称号，满足 `Conditions` 的人按概率获得。共 **368 个**称号有 `AutoLearn`（如晋宣帝、汉献帝、关内侯） |
| 3 | **君主授勋** | `GameScenario.cs:1340 guanzhiDayEvent()` | `ManualAward = true` 的称号由玩家/君主授予，共 **40 个**（县侯、万户侯、魏王、晋王、燕王、蜀王…） |
| 4 | **派城学习** | `Person.GoForStudyTitle`（Person.cs:7545）→ `DoStudyTitle`（Person.cs:7053） | 在城池里选“学习称号”，需 90 天（`LearnTitleDays=90`，或称号 `Kind.StudyDay` 更短），到期判定 |
| 5 | **子女继承** | `InheritChance`（百分比，Person.cs:9423、GameScenario.cs:5806） | 子女出生/继承时按概率获得父/母的同类称号；`名将` 的 `InheritChance=5` |

### 6.2 条件表（ConditionTableString）

- 每个称号的 `ConditionTableString` 是**条件 ID 列表**（空格分隔），对应 `CommonData.json` → `AllConditions.Conditions` 里的条目；学习/自动学习时逐条 `CheckCondition`。
- 条件种类共 347 种，常见的有：拥有某称号(33)、名声/功绩达到(29)、统率/武勇/智谋/政治/魅力达到(各 17–21)、内政经验值达到(15)、拥有宝物(20)、建筑为某类型(12)、在每年某月前后(11/12) 等。
- **特殊条件 ID**：
  - `900` = **无法习得**（不能通过学习/自动学习获得，只能数据预置）
  - `901` = 无法出生自带
  - `902` = 无法出现于生成武将中
- **1302 个称号里 668 个含 900**，其中就包括：妖后降临(10032 Lv12)、天公将军(385 Lv10)、如仙之计(10003 Lv10)、谋战全才(10019 Lv8)、癫倒众生(10052 Lv9)、**名将(220 Lv7，条件 `900 902`)**。

### 6.3 学习成功率

`Person.DoStudyTitle`（Person.cs:7053）：

```csharp
Random(StudyingTitle.Level * 2 + 8) + StudyingTitle.Kind.SuccessRate
    >= StudyingTitle.Level * 2 - Parameters.LearnTitleSuccessRate(100)
```

因为 `LearnTitleSuccessRate=100`、`Kind.SuccessRate` 通常为 0，右边恒为负，所以**只要满足条件就几乎必成功**——真正的门槛是条件表，不是概率。

### 6.4 效果

称号的 `InfluencesString` 指向 `AllInfluences` 的效果条目，加载时一次性加到人物。效果类型包括：属性加值/倍率、战斗攻防、战意/士气、移动、计略成功率、怀孕率、视野、范围光环等。示例：

- 妖后降临 Lv12：怀孕 +75%、友军战意每日 +20、友军攻防 +10%、非友军 30% 混乱。
- 天公将军 Lv10：黄巾系专属大范围加成。

## 7. 技能（Skill）获取机制

- 全库 **79 个**技能（ID 0–78），每个有 `Level`（1–3 居多）、`Conditions`（学习条件）、`InfluencesString`（效果）。
- 获取途径：
  1. **数据预置**：`SkillsString`；
  2. **每日自动学习**：`Person.AutoLearnEvent → AutoLearnSkill`（Person.cs:5107），每天对每个“未拥有且 `CanLearn` 为真”的技能各掷 `Chance(AutoLearnSkillSuccessRate=10)`，中了直接学会。**只对“有归属势力”的人生效**（`BelongedFactionWithPrincess != null`，即人在城里/部队里/为妃/被俘）。所以能否“白嫖”到技能，取决于条件表有多严——条件表就是把关的门；
  3. **派城学习**：`GoForStudySkill`（Person.cs:7497），30 天（`LearnSkillDays=30`），到期 `DoStudySkill`（Person.cs:6917）**一次性遍历所有可学技能**，逐个判定：
     ```csharp
     Random(value.Level * 2 + 8) >= (value.Level + 已学会数) * 2 - LearnSkillSuccessRate(100)
     ```
     因为右边为负，实际是“把所有满足条件的技能一次全学会”。这也是为什么派一次学习常常一次涨好几个技能。

- `CanLearn` 就是 `Conditions.CheckCondition(person)`（`GameObjects.PersonDetail/Skill.cs:210`）。

## 8. 特技（Stunt）获取机制

- 全库只有 **14 种**战斗特技（ID 0–13）：遁走、闪击、铁壁、亢奋、威风、奇袭、犄角、纵火、驱逐、疯狂、稳守、急智、隐忍、攻城。
- 获取途径：
  1. 数据预置：`StuntsString`；
  2. 每日自动学习：`AutoLearnStunt`（Person.cs:5123），每个未拥有且 `IsLearnable` 的特技每天 `Chance(10)`；
  3. 派城学习：`GoForStudyStunt(desStunt)`（Person.cs:7517），60 天（`LearnStuntDays=60`），到期 `DoStudyStunt`（Person.cs:6945）按 `Chance(LearnStuntSuccessRate=100)` 判定，**一次只学指定的那一个**。
- `IsLearnable` = `LearnConditions.CheckCondition(person)`（`GameObjects.PersonDetail/Stunt.cs:234`）。
- 特技是战斗中消耗战意主动释放或被动的战术，和“技能”（常驻被动）不是一回事。

## 9. 数据预置 vs 游戏内成长：为什么超模角色长不出来

| 特征 | 数据预置能做到 | 游戏内成长能做到 |
|---|---|---|
| 五维 | 任意（可超 400 总和） | 单维封顶 400，经验封顶 30 万 |
| 称号 | 任意，包括 668 个“无法习得”的幻想称号 | 只能拿到 368 个可自动学习 + 40 个可授勋 + 部分可学习称号 |
| 技能 | 任意，甚至可写 33 个 | 自动/学习都受条件表限制，且要时间 |
| 特技 | 任意 | 共 14 种，需条件+时间 |
| 悬空引用 | 可以写不存在的称号/技能/特技 ID | 不存在 |

蔡露（五维 456、妖后降临 Lv12、33 技能、5 特技）、朱云玲（如仙之计 Lv10、35 技能）、蓝嘉（谋战全才 Lv8、27 技能）都是**剧本数据里直接写死**的，不是玩家能练出来的组合。

## 10. 一个普通武将的成长时间线（示例）

假设一个初始 统率 60 / 武勇 50 / 智谋 55 / 政治 70 / 魅力 65 的女将，加入玩家势力：

1. **第 1 天**：被招募，`Status = Normal`，进入城池。
2. **内政期**：派去“农业”。农业能力 = 2×(政治 70+魅力 65) = 270；每天获得 ≈ 270/(500+150×0) ≈ 0.54 点“工作值”，取整后大多为 0，偶尔为 1，乘 2 后给政治、魅力各 +0~2 点经验。一年（360 天）大约积累几百点经验，折合属性 +1 上下——**这就是正常武将的成长速度**。
3. **想练统率**：改派“民心”（统率+政治+2×魅力）或“耐久”（四项各 1），或直接进部队训练/打仗（统率涨得最快，主将 ×2）。
4. **技能**：满足条件后，每天 10% 自动学会；或派去城里“学习”30 天，一次性把当前满足条件的技能全部学完。
5. **特技**：每天 10% 自动；或派去学 60 天，指定学一个。
6. **称号**：只能等君主授勋（40 个）、满足条件自动获得（368 个）、或花 90 天学习（若该称号可学且条件满足）。668 个“无法习得”的称号永远学不到。
7. **上限**：单条属性 400，经验 30 万；到顶后工作/战斗只涨名声、功绩、内政经验，五维不再涨。

> 结论：正常成长曲线是“几年才涨十几点”，绝无可能练出 456 五维 + 33 技能。

### 11.3 想要“武将不再变态成长”的三种改法

1. **降倍率**：`AbilityExperienceRate`、`InternalRate`、`TrainingRate` 调小（如 0.5 / 0.5 / 1）。
2. **降上限**：`MaxAbility` 调到 300（注意会影响所有 AI 与玩家）。
