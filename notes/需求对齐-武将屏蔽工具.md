## 用户目标（原文）

> 当前目前下的游戏如果要改的话是否要逆向，我想要一个可视化工具可以编辑游戏内容，包括把哪些武将不上场（目前游戏加了很多超模女性武将） 先不动手，对齐需求再改

## 结论：不需要逆向

- 游戏是 .NET Framework 4.8 / C#（MonoGame），exe 旁带 pdb，已用 ILSpy 反编译出完整可读工程：`D:\re\zhongsan\ilspy\`。
- 全部数据是明文 JSON：`Content\Data\Scenario\*.json`（26 个剧本）、`Content\Data\Common\CommonData.json`、存档 `%USERPROFILE%\Documents\WorldOfTheThreeKingdoms\Save\*.json`。
- 官方自带 `WorldOfTheThreeKingdomsEditor.exe`（WPF），可打开剧本与存档 —— 说明数据格式本来就是为外部编辑设计的。
- 逆向只在"改规则"（新增名单机制、改公式）时才需要，本项目不需要。

## 四项决策（2026-11-01 用户确认）

| 项 | 决定 |
|---|---|
| 生效层 | **剧本 + 存档都改**（当前档立即生效，且以后新开档也干净） |
| "不上场"语义 | **彻底消失**：`Alive=false` + `Available=false` + 清理城池/部队/俘虏等处的 ID 引用 |
| 工具形态 | **.NET 8 单文件桌面 exe**（双击即用，直接读写文件，无需安装） |
| 名单维护 | **规则批量勾选 + 手动微调**（如"9000 段女性""五维≥300 的女性"，逐行可取消） |

## 关键机制（来自反编译源码，实现必须遵守）

- 出场判定：`GameObjects\Person.cs:7896 MeetAvailableCondition()`
  `Alive && !Available && YearAvailable <= Date.Year && (ID 段开关)`；
  `GameScenario.cs:3810` 每月对全体人物调用 `TryToBeAvailable()`（`Person.cs:8618`，20% 命中）。
- 在场名单重建：`GameScenario.cs:3037` `if (person.Available && person.Alive) AvailablePersons.Add(person)`；
  归属来自空格分隔的 ID 字符串：`Architecture.PersonsString / MovingPersonsString / NoFactionPersonsString /
  NoFactionMovingPersonsString / feiziliebiaoString`（`Architecture.cs:11528 LoadPersonsFromString`）、
  `Troop.PersonsString + LeaderIDString`（`GameScenario.cs:3408`）。
- `Faction.Persons` 是派生属性，不落盘。
- 载入器：`SimpleSerializer.DeserializeJsonFile<GameScenario>` → `DataContractJsonSerializer`（成员顺序敏感、忽略未知成员）。
  **工具必须原序回写、不增删字段。**
- 游戏有 MOD 覆盖机制（`PlatformBase.cs:458 GetMODFile`）：`MODs\<n>\Content\...` 可覆盖任意数据文件，不动安装目录也能生效。

## 工具功能范围（v1）

1. 打开剧本 / 存档；表格展示武将（性别、五维、已登场、存活、出场年、所在、势力）；可按任意列排序。
2. 筛选：姓名搜索、性别、ID 段、登场状态、五维阈值、是否已勾选。
3. 批量规则勾选 + 逐行手动调整；名单可导出/导入（`blocklist.json`）。
4. 双击查看并编辑单个人物的全部 118 个字段（含五维、出场年、存活、性别等）。
5. 应用：备份 → 写入 → 生成变更报告（含引用冲突告警：势力君主、部队主将、配偶等）。
6. 同一份名单可应用到第二个文件（先改剧本、再改存档）。

## 安全策略

- 写入前自动备份到 `D:\re\zhongsan\backup\`（`<文件名>.bak.<时间戳>.json`）。
- 原子写入：先写 `.tmp` 再替换。
- 拒绝处理 gzip 加密存档（`EncryptSave=True` 的情况），提示先关闭加密。
- 不新增/删除 JSON 字段，只改已有字段的值，保持成员顺序。
